# branding-shared

Núcleo compartilhado de marca por tenant (client-side), usado pelos produtos Lemebel via CDN (jsDelivr). Repositório público de propósito — código servido direto no navegador não consegue autenticar, e não contém segredo nenhum (só a chave pública "anon" do Supabase, que já é pública por natureza).

Consumido hoje por `lemebel-qualidade` e `lemebel-consultoria`. Ver comentário no topo de `tenant-branding-core.js` para a interface de configuração.
